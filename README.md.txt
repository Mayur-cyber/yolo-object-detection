# YOLO Object Detection

Real-time object detection using YOLOv8 and OpenCV.

## Features
- Image detection
- Video detection
- Live webcam detection

## Installation
pip install -r requirements.txt

## Usage
python main.py
python videodetect.py
python webcam.py

## Tech Stack
- Python 3.13
- YOLOv8 (Ultralytics)
- OpenCV
